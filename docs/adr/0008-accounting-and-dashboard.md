# ADR-0008: 财务对账与数据看板

## Status
Accepted

## Date
2026-09-18

## Context
Q(S6) 答为 **d+a(实时看板 + CSV 导出)**。

## Decision

### 实时看板(S6=d)
- 本月累计返利成本(已计入余额 + 待定)
- 上月对比 + 趋势图
- 核心指标:合格订单数 / 邀请人数量 / 提现申请数 / 待审提现数
- 数据更新频率:分钟级

### CSV 导出(S6=a)
- 按日 / 按周 / 按月导出订单明细、返利明细、提现明细
- 中文表头,UTF-8 with BOM,Excel 直接打开
- 涉及数据下载审计(谁、什么时候、导了什么)

### 数据口径
- **返利成本** = 已计入余额的返利 + 当前待定返利
- 不含已退款对应扣回的返利
- 已核销 + T+7 无退款 的订单计入「已计入余额」
- 已核销 + 仍在 T+7 缓冲期 的订单计入「待定」

## Consequences
- (+) 看板满足日常运营决策
- (+) CSV 兼容店主自有记账流程
- (-) 看板数据需准实时(分钟级),对数据库有压力——需要物化视图或预聚合表
- (-) CSV 导出涉及数据下载审计,需日志留存
- (-) 数据口径一旦确定,后续若改需明确「按新口径重算历史」的范围
