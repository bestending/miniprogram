# ADR-0004: 返利窗口机制(店主自配节假日 + 月度触发日)

## Status
Accepted

## Date
2026-09-18

## Context
小店不适合终身返利(成本不可控),需要把返利集中在「营销敏感期」。Q5 答为 d(节假日 + 月15日);Q5a 答为 a(月15日为触发日);Q5b 答为 a(店主自配节假日)。

节假日清单由谁决定、月15日是触发还是结算,需要明确。

## Decision

### 节假日活动
- 由**店主**在管理后台自行配置节假日清单、起止日期与返利比例
- 平台提供节假日模板(春节/中秋/国庆等)与默认比例作为参考
- 店主可创建、修改与停用任意活动;节假日期间返利比例允许高于默认 10%

### 每月 15 日
- **角色:触发日**——仅 15 日 0:00–23:59 当天的订单进入返利计算
- 非节假日期间,月15日为月度仪式日
- 节假日与月15日重叠时,只触发一次返利(取较高比例)

### 生效顺序
1. 先按店主配置的节假日活动匹配
2. 无匹配时,检查是否月15日
3. 两者皆否,不计入返利

## Consequences
- (+) 节假日集中爆量能直接拉动到店
- (+) 月15日作为月度仪式日,降低终身返利的成本风险
- (+) 店主灵活度高,可针对本店节奏调整
- (-) 店主需要主动运营——忘记配则该期订单一律不返
- (-) 节假日 + 月15日重叠时,需明确只触发一次(避免重复返利)
- (-) 月15日的「触发日」性质意味着任何一天的「补单/补救」无法获得返利
