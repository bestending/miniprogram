# ADR-0002: 返利状态机与退款回收规则

## Status
Accepted

## Date
2026-09-18

## Context
返利从下单到余额到账需要可观测的状态,避免被退款穿透。Q6、Q7 涉及两个问题:
- 何时"赚到"、何时"可用"?
- 已计入余额的返利在退款发生时如何处理?

不设缓冲期会导致大量薅羊毛(下单-退单-返利到手);设过长缓冲期会伤害邀请人兑现感。

## Decision

### 状态机
`已支付 → 已核销 → T+7 无退款 → 计入余额 → 90 天有效`

- **已支付**:订单支付完成,返利进入「待定」状态
- **已核销**:顾客到店完成消费,核销不改变返利状态(继续待定)
- **T+7 无退款**:自支付起 7 天内无退款,返利从「待定」转为「已计入余额」
- **已计入余额**:可用于消费核销或提现
- **90 天有效**:余额 90 天内未使用则清零

### 退款回收
- 订单**全额退款**:扣除对应的「待定」返利;若已计入余额,扣回对应金额(允许负数,下次消费优先抵扣)
- 订单**部分退款**:按比例扣减「待定」返利;若已计入余额,按比例扣回

## Consequences
- (+) T+7 缓冲期挡住绝大多数退款套利
- (+) 按比例扣减兼顾体验与商家利益
- (-) 邀请人需等 7+ 天才能看到余额增长,体验略慢
- (-) 90 天有效期对邀请人记忆有要求,需要主动提醒(余额到期前 N 天通知)
- (-) 部分退款 + 已计入余额的场景,扣回逻辑需要精细设计(避免重复扣)
