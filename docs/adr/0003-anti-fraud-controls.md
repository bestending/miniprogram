# ADR-0003: 反作弊四件套(首单领码 / 一次绑定 / 限额 / 同设备硬规则)

## Status
Accepted

## Date
2026-09-18

## Context
微信生态下薅羊毛门槛低,需要多重防线。Q8 答为 a+b+c+d 全选:
- (a) 新用户首单支付完成后才能领取邀请码
- (b) 同一被邀请人只能绑定一次邀请人
- (c) 同一邀请人每日/月返利上限
- (d) 同设备/IP/手机号 不可互邀

grilling 阶段曾建议 (d) 改为软规则(行为画像),但用户选择保留硬规则——小店场景下店主对「防自邀、家庭圈薅」诉求强烈。

## Decision
采用四件套硬规则:

1. **首单领码**:未完成首单支付的用户,「我的 → 邀请码」入口不可见
2. **一次绑定**:被邀请人一旦绑定邀请码,本微信 OpenID + 关联手机号账户在系统中只能绑定一次,不可换码
3. **返利限额**:同一邀请人每日返利累计上限 + 每月返利累计上限(默认日 50 / 月 200,具体值在运营后台可调,首期数据后优化)
4. **同设备/IP/手机号硬互斥**:同一物理设备(微信设备指纹)、同一 IP 段、同一手机号不可互为邀请人与被邀请人

## Consequences
- (+) 四道防线互相补足,显著降低薅羊毛空间
- (+) 店主对「防自邀」诉求被满足
- (-) (d) 同设备硬规则会误伤「换微信的家庭成员」「共用手机点单」等场景
- (-) 若后续要支持「家庭/同事推荐」功能,需要重新设计 (d) 为软规则 + 白名单
- (-) 限额初始值需要小范围灰度测试,避免误伤正常邀请人
