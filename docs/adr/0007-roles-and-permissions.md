# ADR-0007: 角色与权限分层(店主 + 店员)

## Status
Accepted

## Date
2026-09-18

## Context
Q(S2) 答为 **b(店主 + 店员分层)**。Q(S5) 进一步规定「只有管理员(店主)可审核提现」。

## Decision

两级角色:

| 能力 | 店主 | 店员 |
|------|------|------|
| 配置节假日活动 | ✅ | ❌ |
| 审核提现申请 | ✅ | ❌ |
| 查看订单明细与邀请人列表 | ✅ | ✅ |
| 添加 / 移除本店店员 | ✅ | ❌ |

店主本人持有邀请码是允许的——自己邀请自己会被反作弊规则挡住(见 ADR-0003),但**店主审核自己的提现存在利益冲突风险**。首期接受该风险,后续如出现薅羊毛案例,在本 ADR 内追加规则(如同一店主本人提现自动转平台复审)。

## Consequences
- (+) 简单清晰,小店足够
- (+) 店主灵活度高,可随时调整节假日活动与审核决策
- (-) 店主本人的提现由自己审核,存在利益冲突(待首期数据观察)
- (-) 若后续要加平台运营监管,需要升级为三层角色(店主 + 店员 + 平台运营)
