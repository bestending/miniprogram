# ADR-0001: 返利成本由门店全额承担

## Status
Accepted

## Date
2026-09-18

## Context
返利成本需要明确归属方。可选项:
- (a) 门店全额承担(单店或小连锁)
- (b) 品牌总部承担(中大型连锁)
- (c) 总部 + 门店分摊(常见 5:5 或 7:3)
- (d) 平台/第三方补贴(美团、抖音券模式)

当前项目面向小店(单店或小连锁),业务体量小,无总部统一预算诉求。Q4 首轮答为"暂定 a",最终一轮未提出异议。

## Decision
返利成本由**单店全额承担**,从门店营业收入中列支。

## Consequences
- (+) 实施简单,财务流程短,商户可直接控制
- (+) 不需要总部/平台介入,与当前小店主自营模式契合
- (-) 成本直接压缩单店毛利,节假日集中返利窗口可能造成短期亏损
- (-) 后续若扩为多店/连锁,需要重新拆账,会带来历史包袱
