# ADR-0005: 余额提现规则(150 阈值 + 100 元/月上限)

## Status
Accepted

## Date
2026-09-18

## Context
余额若不能提现会伤害邀请人信任,全额可提现则会被薅羊毛。Q9 答为 b(满 X 元可提现),具体阈值与上限需要确定。

提现涉及对接微信支付商户号企业付款能力,需要手续费与资质准备。

## Decision

1. **提现阈值**:返利余额累计 ≥ **150 元** 后开放提现入口
2. **提现上限**:每个邀请人**每月最高提现 100 元**(默认值,运营后台可调)
3. **提现渠道**:通过商户号企业付款 API,资金到账邀请人微信零钱
4. **低于阈值余额**:仅能消费核销,不可提现
5. **提现审核**:首期人工抽查;后续可改为风控触发审核

## Consequences
- (+) 150 阈值 + 100/月上限确保商家成本可控
- (+) 给邀请人明确兑现感,激励持续邀请
- (-) 需要商户号具备企业付款能力,涉及资质与手续费(微信企业付款费率约 1%)
- (-) 邀请人若余额未满 150 元,体验感差——需配合「还差 X 元即可提现」提醒文案
- (-) 首期人工审核增加运营成本
- (-) 100 元/月上限对高频邀请人偏紧,可能造成邀请动机下降——需根据首期数据优化
